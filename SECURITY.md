# Security & Privacy Policy

## Reporting an issue

If you discover a security or privacy issue in this repository (for example,
an accidental secret, credential, or private data disclosure), please report
it privately rather than opening a public issue, so it can be addressed
before wider disclosure.

## What must never be published here

EXPC-GVP is a **public** repository. The following must never be committed:

- Secrets, credentials, API keys, tokens, or connection strings.
- Private or personal user data of any kind.
- Client names, client-identifying information, or anything scoped to a
  private/organizational context that is not meant to be public.
- Raw dictation logs, transcripts, or spoken-form captures tied to a real
  person or private session.
- Any other personal phrase or data point that was not explicitly reviewed
  and approved for the **public** Global Vocabulary Pack.

Personal and organization-scoped vocabulary layers (see `README.md`) are, by
design, out of scope for this public repository.
